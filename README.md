# Иван Груздев - ML Engineer

Статический сайт-резюме с кейсами CV, LLM, VLM, OCR и NLP. Содержимое доступно без JavaScript; скрипты добавляют меню, управление видео и декоративный фон.

Русский язык открывается по умолчанию (`/`). Переключатель RU / EN в шапке ведёт на русскую или английскую страницу (`/en.html`), в том числе без JavaScript. PDF-резюме и демонстрационные материалы остаются на языке оригинала.

## Разработка

Нужны Node.js 24, pnpm 11 и Python 3 для локального сервера.

```sh
pnpm install --frozen-lockfile
pnpm build
python3 -m http.server 8010 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8010/. После изменения исходников повторить `pnpm build` и обновить страницу.

- `src/content.mjs` - данные кейсов, описания направлений и стек.
- `src/render.mjs` - шаблоны разделов, общая информация, опыт, образование и контакты.
- `src/index.html` - HTML-оболочка, главный экран и метаданные.
- `src/translations.en.json` - английские переводы текстов и атрибутов.
- `src/localize.mjs` - генерация английской страницы; отсутствие перевода останавливает сборку.
- `src/styles.css` - стили и адаптивные правила.
- `src/app.js` - меню, видео и уведомления.
- `src/animation.js` - независимая необязательная анимация.
- `dist/` - результат сборки; изображения, PDF и видео находятся в `dist/assets/`.

HTML, CSS и JS в `dist` генерируются из `src`: редактировать их напрямую не нужно. Сборка автоматически обновляет версии CSS/JS в ссылках.

## Проверки

```sh
pnpm check
pnpm exec playwright install webkit chromium
pnpm test
```

Проверяются локальные ресурсы, якоря, уникальность HTML id, работа без JS, отложенная загрузка и управление видео, меню и ширина страницы на 390/768/1440 px. WebKit выбран для воспроизведения H.264, который отсутствует в некоторых сборках Chromium для тестирования.

GitHub Actions собирает страницу и выполняет проверки перед публикацией `dist` на GitHub Pages. Публикация запускается при push в `main`.
